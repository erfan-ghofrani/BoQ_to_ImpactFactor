# Synthetic example data

Every file in this folder was created specifically for the public repository.

- `demo_boq.pdf` is an artificial BoQ-like PDF.
- `reference_database.csv` contains fictitious reference-task/material records.
- `impact_factors.csv` contains fictitious environmental factors.
- `spanish_stopwords.txt` is a short example stop-word list.

These files are not extracted from the residential case study and are not
copied from BCCA or ecoinvent.
